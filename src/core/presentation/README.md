# Presentation do core

Fronteira para controllers/DTOs, guards, pipes, filters e interceptors Nest. Nenhuma rota de autenticação foi aberta nesta etapa.

O futuro HTTP adapter deve validar entrada, construir client binding confiável, limitar tentativas e traduzir erros sem expor credenciais. Guard deve verificar token, sessão ativa e acesso atual. Controllers só serão registrados com todas as portas necessárias.
